# 逐步详解系列

面向 CV 工程师的**全流程原理拆解**页面：每一步的输入输出、公式、超参数、为什么必须在这个位置、跳过会怎样。两篇都是**纯静态、零外部依赖**的交互式 HTML，双击即可离线阅读。

| 主题 | 入口 | 内容 |
|---|---|---|
| **ISP 管线** | [`isp/index.html`](isp/index.html) | 从光子到 YUV：BLC / LSC / DPCC / 去马赛克 / AWB / CCM / Gamma / YUV / 3A，10 章 + 6 个交互演示 |
| **R-CNN** | [`rcnn/index.html`](rcnn/index.html) | 候选区域 → 227×227 归一化 → CNN 特征 → SVM → 边框回归 → NMS，12 章 + 9 个交互演示 |

## ISP 管线：十章内容

| 章 | 内容 |
|---|---|
| 01 总览 | 全链路方框图、线性域/感知域的分界、四个必须记住的结论 |
| 02 成像物理 | 像素剖面（微透镜/CFA/遮光层/光电二极管）、Bayer 四相位、噪声模型（散粒 + 读出）、黑电平与量化 |
| 03 RAW 校正 | BLC、LSC（cos⁴ 与增益网格）、DPCC（坏点表 vs 中值盲修）、RAW 域降噪；域与顺序的硬约束 |
| 04 去马赛克 | 双线性 / Malvar-He-Cutler 5×5 / 方向自适应；伪彩与拉链伪影的成因；PSNR 与观感的差别 |
| 05 白平衡 | 为什么只有 2 个自由度；灰度世界 / 白点法 / Shades-of-Gray / 相关性方法的假设与死法 |
| 06 CCM 与 Gamma | 最小二乘标定 CCM、行和约束；sRGB 与 BT.709 传递函数、色调映射与 HDR |
| 07 YUV 域 | BT.601 vs BT.709、Y′≠luminance、4:2:0、Y 锐化与 UV 降噪、ISP 的 line buffer 约束 |
| 08 3A 闭环 | AE（曝光时间 vs 增益、防闪烁）、AWB 时域平滑、AF 三条路线、回路耦合 |
| 09 工程实践 | RAW / YUV / RGB 取数位置对比、训练-部署一致性清单、bring-up 常见错误 |
| 10 速查与自测 | 一页速查、6 道自测题、文献出处（含「知乎专栏未能核对」说明） |

## R-CNN：六步流程逐步拆解

| 章节 | 内容 |
|---|---|
| 01 总览 | 六步流程图、每步的输入输出规格、为什么值得抠细节 |
| 02 第 1 步 | **候选区域生成**：Felzenszwalb 过分割 → 四种相似度（颜色/纹理/尺寸/填充度）的公式与直觉 → 80 组多样性配置 → 截断到 K=2000；召回率 98% 的含义 |
| 03 第 2 步 | **区域归一化到 227×227**：三种缩放策略对比（warp / crop / 带上下文）、p=16 均值像素填充、完整数值流程、预处理四个必查项 |
| 04 第 3 步 | **CNN 前向提取 fc7**：AlexNet 逐层规格与参数量（含 LRN、重叠池化等易错细节）、为什么取 fc7、为什么这一步占 95% 耗时（含 FLOPs 估算） |
| 05 第 4 步 | **逐类线性 SVM**：hinge loss 目标函数、one-vs-rest 的 21 个分类器、为什么不用 softmax（含消融数据与根因）、难例挖掘五步流程 |
| 06 第 5 步 | **边框回归**：编码/解码公式的推导与直觉（中心点归一化、宽高取 log）、岭回归目标、λ=1000、只用 IoU≥0.6 的样本 |
| 07 训练 | **四个阶段与全部超参**：ImageNet 预训练 → 域内微调（学习率 0.001、30k 迭代、32 正 + 96 负）→ 抽 fc7 训 SVM → 抽 pool5 训回归器；超参数总表 |
| 08 推理 | **单步拆解与计时**：可复现的伪代码、VGG16 版实测耗时占比（③ 步 95%） |
| 09 NMS | **后处理与输出格式**：贪心 NMS 伪代码、输出六元组、R-CNN 里 IoU 出现五次的对照表 |
| 10 速查 | 六步速查表、12 个复现坑、FAQ 10 问 |
| 11 代码 | **手写 NMS / IoU / 边框回归编解码**（不到 80 行），以及用 torchvision 算子验证每个公式 |
| 12 自测 | 8 道题，点击立即判分并给解析 |

### 9 个交互演示（R-CNN）

| # | 位置 | 你能动手做什么 |
|---|---|---|
| 1 | 第 1 步 | 拖动 K 与 IoU 阈值，看候选框数量如何影响召回率与 ③ 步的计算量 |
| 2 | 第 2 步 | 拖动候选框、切换 warp/crop、调上下文 p，实时看 227×227 输出形状如何被改变 |
| 3 | 第 3 步 | 逐层查看 AlexNet 的张量尺寸、参数量、计算量，以及参数分布条形图 |
| 4 | 第 5 步 | **边框回归编解码计算器**：拖 P 与 G 看 t 的计算，拖 d 看解码结果，一键设为「完美回归」 |
| 5 | 第 7 步 | 估算特征缓存与 patch 缓存的数据量（fc7 / pool5 / 原图 patch） |
| 6 | 第 8 步 | 点击推理流水线的任一阶段，看输入输出规格、可学习性与耗时占比 |
| 7 | 第 9 步 | 拖两个框实时算 IoU；拖阈值看 14 个检测框哪些被 NMS 抑制 |
| 8 | 第 12 步 | 自测题，点击判分 + 解析 |

## 本地自检

修改页面后可以跑一遍（需要 Python 3 与 Node.js，均只用标准库；在 `deep-learning-frameworks/` 目录下执行）：

```bash
python tools/check_html.py .          # HTML 结构：标签配对、重复 id、资源与锚点引用
python tools/check_ids.py             # JS 引用的 #id 是否都存在于页面
node tools/dom_smoke.js isp/index.html site.js isp.js     # 模拟 DOM 中真实执行脚本
node tools/dom_smoke.js rcnn/index.html site.js rcnn.js
```

自检覆盖结构、引用与运行时异常，但**不覆盖画面布局**。改演示后建议用无头浏览器截屏核对（把 `<仓库路径>` 换成实际路径）：

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu `
  --virtual-time-budget=8000 --window-size=1500,15000 --screenshot=page.png `
  "file:///<仓库路径>/deep-learning-frameworks/isp/index.html"
```
